# 角色信息需求表

> 用途：一次性收集「群 + 本人 + 2–3 个成员」的信息，避免在设置页来回拼。
> 可以直接复制给生成模型，也可以按表填好后录入插件。
> 原则：**公开信息**和**私有信息**分开写；秘密只写一次；关系写“称呼 + 态度 + 发生过什么”。

## 最快填写版

```text
群名：
群简介（时间 / 地点 / 当前局势 / 基调）：

本人：
- 名字：
- 一句话：
- 设定：

成员 A：
- 名字：
- 一句话：
- 说话方式：
- 核心设定：
- 与本人 / 其他成员的关系：

成员 B：
- 名字：
- 一句话：
- 说话方式：
- 核心设定：
- 与本人 / 其他成员的关系：

成员 C（可选）：
- 同上

额外要求：
- 这个群现在最紧张/最好笑/最暧昧的点：
- 绝对不能出现的内容：
```

## 1. 群信息

| 字段 | 填什么 | 限制 / 建议 |
|---|---|---|
| 群名 | 一眼能记住的场景名 | ≤ 40 字 |
| 群简介 | 时间、地点、当前事件、气氛、大家为什么在这里 | ≤ 2000 字 |
| 当前局势 | 现在正在发生什么，谁在等谁回答 | 1–3 句 |
| 群基调 | 日常 / 悬疑 / 工作 / 冲突 / 暧昧 / 喜剧 | 选 1–2 个 |
| 额外禁忌 | 不能出现的行为、话题、称呼 | 可选 |
| 接话概率 | 其他成员主动接话的概率 | 0–100，默认 30 |
| 最多目标数 | 一条消息最多几个人必答 | 1–3，默认 2 |
| 群模型 | 跟随宿主默认，或从目录选 provider / model | 可选 |

## 2. 本人角色

| 字段 | 填什么 | 限制 / 建议 |
|---|---|---|
| 名字 | 你在这个群里的名字 | ≤ 16 字，不能与成员重名，不能含空格 / `@` / 标点 |
| 一句话 | 别人第一眼怎么看你 | ≤ 400 字 |
| 设定 | 身份、当前状态、你想要什么、你不想被怎样对待 | 建议 300–1000 字 |
| 与成员关系 | 对每个成员：称呼 + 态度 + 一件具体的事 | 每人 ≤ 200 字 |
| 头像 | 可选 | PNG / JPEG / WebP |

## 3. 每个成员

2–3 人，每人填一份。

| 字段 | 填什么 | 限制 / 建议 |
|---|---|---|
| 名字 | `@` 使用的显示名 | ≤ 16 字，全群唯一，不能含空格 / `@` / 标点 |
| 公开一句话 | 全群都能看到的人设摘要 | ≤ 400 字 |
| 说话方式 `style` | 句长、称呼、口头禅、语气、标点习惯 | ≤ 300 字；只给本人 prompt 看 |
| 核心设定 `core` | 身份、目标、性格、说话方式、底线、秘密 | 建议 ≤ 4000 字 |
| 扩展设定 `extended` | 过去经历、世界观细节、支线 | 可选，建议 ≤ 8000 字 |
| 公开关系 | 对其他成员 / 本人的公开态度 | 每人 ≤ 200 字 |
| 私人关系 | 只有本人知道的真实看法 | 每人 ≤ 200 字，默认不导出 |
| 私有记忆 | 只有本人记得的事、误会、承诺、把柄 | ≤ 4000 字，默认不导出 |
| 模型覆盖 | 跟随群 / 宿主默认，或单独选 | 可选 |
| 头像 | 可选 | PNG / JPEG / WebP |

### 核心设定的推荐结构

```text
【身份】是谁、做什么、在什么位置。
【目标】现在最想要什么；最怕失去什么。
【性格】遇到压力、被追问、被示好时分别怎么反应。
【说话】句子长短、称呼、口头禅、会不会反问、会不会沉默。
【关系】对在场每个人的称呼和态度。
【底线】绝对不会做什么、不会说什么。
【秘密】只有自己知道的事；被追问时是否认、转移话题，还是沉默。
```

## 4. 关系矩阵

公开关系填在成员卡里；私人关系只给本人看。

| 角色 | 对本人 | 对 A | 对 B | 对 C |
|---|---|---|---|---|
| 本人 | — |  |  |  |
| A |  | — |  |  |
| B |  |  | — |  |
| C |  |  |  | — |

建议写法：

- 公开：`叫“管理员”，表面客气，实际在盯进度`
- 私人：`其实怕他逞强，但不想让他看出来`
- 不要写：`关系很好`、`很复杂`——太抽象，模型无法演。

## 5. 秘密与底线

| 角色 | 秘密 | 谁知道 | 被追问时 | 绝对底线 |
|---|---|---|---|---|
| A |  |  | 否认 / 转移 / 沉默 / 说一半 |  |
| B |  |  |  |  |
| C |  |  |  |  |

秘密会进入该成员的私有记忆或核心设定，**不要**写进公开一句话和公开关系。

## 6. 给生成模型的简短指令

```text
请根据上面的表生成/补全 2–3 个角色。
要求：
1. 每个角色分开写，不要写成小说。
2. 名字、称呼、秘密、底线必须前后一致。
3. 公开信息、私人关系、私有记忆分开输出。
4. 不要替别人说话，不要替别人做决定。
5. 不知道的字段标注“待定”，不要编造关键设定。
```

## 7. 与插件字段对应

| 表里的字段 | 插件里的位置 |
|---|---|
| 群名 / 群简介 | 新建群 / 群设置 |
| 本人名字 / 一句话 / 设定 | 管理 → 我的角色 |
| 公开一句话 | 成员 → 公开档案 · 一句话 |
| 说话方式 | 成员 → 说话方式（style） |
| 核心设定 / 扩展设定 | 成员 → 核心设定 / 扩展设定 |
| 公开关系 | 成员 → 公开关系 |
| 私人关系 | 成员 → 私人关系（只给本人看） |
| 私有记忆 | 成员 → 私有记忆（只给本人看） |
| 接话概率 / 最多目标数 | 群设置 → 接话与路由 |
| 模型覆盖 | 群设置 / 成员 → 模型服务商 + 模型 |

## 8. 最小可用版本

如果只想快速开一个群，至少填：

- 群名
- 群简介（3–5 句）
- 本人名字 + 一句话
- 2 个成员：名字 + 一句话 + 核心设定 + 对彼此/本人的关系

其他字段可以进群后再补。私有记忆和私人关系建议先留空，等角色跑几轮再写，避免一开始就把秘密写死。

# v1.3.0 · 私有记忆、私人关系与可重复 QA

## 新增

- **成员私有记忆**：每个成员一份 `setting/memory.md`，只进入该成员自己的 prompt 尾部。
- **私人关系**：每个成员可单独记录对其他成员的私下看法，存入 `card.json.privateRelations`，只给本人看。
- **管理页编辑**：成员表单新增「私有记忆」和「私人关系」；保存后立即持久化，重启/重放不丢。
- **默认不泄露**：群/成员卡导出默认不含私有字段；只有显式勾选「包含私有记忆」才写入，文件名带 `.private.`。
- **说话方式 `style`**：称呼、句长、语气独立成字段，只在本人 prompt 中出现。
- **prompt 分层**：角色核心 / 扩展 / 说话方式 / 本人关系 / 最近说过 / 私有记忆 / 私人关系 / 场景 / 任务 / 提醒；system 前缀保持稳定。
- **可重复 QA**：86 条路由样本、25 个角色场景、漂移指纹、`bystanderChance` / `maxMentionReplies` 扫描。

## 隐私

- 私有字段不进入群简介、system 前缀、路由器或其他成员的 tail。
- 默认导出不含私有字段；`.private.*.json` 与 `members/*/setting/memory.md` 已加入 `.gitignore`。
- 角色评测 fixture 全部为合成场景，不包含真实聊天记录或真实秘密。

## 验证

- 92 项确定性测试通过。
- 本地路由基线：67/67 确定性样本全绿，整体 top-1 96.5%，micro F1 0.958。
- 角色 dry-run：25 个场景 / 29 条 prompt，system 前缀跨轮稳定且不含秘密。
- `npm pack --dry-run` 不包含 `qa/`、测试或运行时数据。

## 安装

```bash
dsh plugin --profile web add "https://github.com/zhdzh-good/multi-role-groupchat/releases/download/v1.3.0/zhdzh-good-multi-role-groupchat-1.3.0.tgz"
```

安装或升级后刷新 Web 页面。数据保存在 `$DSH_HOME/plugin-data/multi-role-groupchat/`，重新安装不会删除群聊数据。

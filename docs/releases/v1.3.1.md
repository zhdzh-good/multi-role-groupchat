# v1.3.1 · 模型下拉选择

## 新增

- 群级模型覆盖与成员级模型覆盖都改为 **provider / model 两级下拉**，不再要求手敲模型 ID。
- 模型目录来自宿主已注册的 provider：
  - `/api/groupchat.models` 返回 provider 名称、模型名称与错误信息。
  - 下拉显示 `名称 · id`，避免同名模型选错。
- 目录加载中显示「正在读取模型目录…」，不会误保存空值。
- 目录读取失败：
  - 显示可读错误和「重试」按钮。
  - 回退为手动输入，避免目录故障阻断配置。
- provider 没有返回模型、或宿主未注册 provider 时：
  - 明确提示原因。
  - 保留手输回退。
- 当前已保存的 provider/model 不在目录里时：
  - 仍显示为「当前」选项，不会因为打开设置页而被清空。

## 兼容性

- 群/成员模型覆盖的数据结构不变：`{ provider, model }`。
- 旧配置、导入的角色卡/群配置、成员级覆盖继续可用。
- 只有「跟随宿主默认」时仍然不需要选择模型。

## 验证

- 92 项确定性测试通过。
- `npm pack --dry-run`：17 个文件，不包含 `qa/`、测试或运行时数据。
- 已用干净 `DSH_HOME` 安装 tarball，并在 `--dump-config` 中确认 bundle 行。

## 安装

```bash
dsh plugin --profile web add "https://github.com/zhdzh-good/multi-role-groupchat/releases/download/v1.3.1/zhdzh-good-multi-role-groupchat-1.3.1.tgz"
```

安装或升级后刷新 Web 页面。

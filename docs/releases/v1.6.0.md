# v1.6.0 · 消息搜索与场景便签

## 新增

### 群内消息搜索

- 顶部搜索按钮，搜索当前群全部历史，包括已折叠消息。
- 可以按角色过滤；结果显示角色、时间、命中片段和「已折叠」标记。
- 点击结果会展开历史、自动渲染到目标消息、滚动到目标并高亮。
- 单一群最多显示 50 条结果。
- 搜索跳转到已折叠的旧消息时，高亮期间保持完整不透明度；4 秒后恢复折叠样式。

### 场景便签

- 聊天右侧新增便利贴，点一下直接编辑，不需要打开管理。
- 可以记录时间、地点、天气、气氛；支持保存、取消、清空和收起。
- 最多 800 字；保存后每轮注入成员 prompt 的 `=== 当前场景 ===`。
- 群导出 / 导入会保留场景；旧群没有该字段时按空场景处理。
- 窄屏时便利贴移到右下角，避免遮挡顶部。
- 只是手动便签，不会自动推进剧情。

### 可读性修正

- 搜索命中的已折叠消息在聚焦期间不再被折叠透明度压暗。

## 兼容性

- 数据格式没有 `schemaVersion` 变更；`scene` 是群文档的可选新增字段。
- 旧群、角色、消息、钉住、私有记忆、导入导出继续可用。
- 搜索只搜当前群，不跨群；场景便签不会自动推断时间或推进剧情。

## 安装

```bash
dsh plugin --profile web add "https://github.com/zhdzh-good/multi-role-groupchat/releases/download/v1.6.0/zhdzh-good-multi-role-groupchat-1.6.0.tgz"
```

安装或升级后重启 `dsh web` 并刷新页面。
